# SELLPAL-INVERCAJAS
Sistema de Gestión Comercial, Inventarios y Pedidos

  Descripción: plataforma web desarrollada para la empresa INVERCAJAS, orientada a optimizar la gestión comercial, el control de productos y el seguimiento de ventas.El sistema permite centralizar la información de clientes, productos y transacciones, facilitando la toma de decisiones mediante informes claros y automatizados
Instalación:NO requiere instalación ya que es una plataforma web
Uso:Uso: El sistema SELPAL se utiliza de la siguiente manera:
Gestión de productos (crear, editar, eliminar). Usuarios administrativos. Consulta informes de ventas. Supervise el inventario. Consulta productos disponibles. Gestiona clientes
